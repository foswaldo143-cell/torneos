# Ideas para más adelante

No se trabajan todavía; quedan registradas para retomarlas.

- **Torneos grandes con premio físico.** Cuando se haya reunido un fondo, hacer torneos especiales donde el ganador se lleve un teléfono u otro premio. (13/10/2026)
- **Clasificatorios en el portal.** Rondas clasificatorias para llegar a esos torneos grandes, gestionadas desde la web. (13/10/2026)
- **Torneos temáticos gratis.** Solo escopetas, solo francotirador, etc., para hacer comunidad fuera del torneo pago. (13/10/2026)
- **Dúos y escuadras.** Escuadras los fines de semana. (13/10/2026)
- **Expansión internacional.** Entre el mes 3 y el 5, con cobros y pagos por Binance. (13/10/2026)
- **Ingresos extra.** Venta de CP, paquetes de entradas, membresía VIP, patrocinios. (13/10/2026)
- **Tercer moderador.** Socio minoritario o con salario. (13/10/2026)
